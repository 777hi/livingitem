## 红电系统「网络级共振」设计定稿（讨论完成，尚未实现）
- 背景：电力层锈蚟原本只有「同氧化级连通、异级不互通」的二值网络隔离，功能上无意义（电力可互换，不需要 4 个独立电网）。
- 定稿方案：**锈蚟 = 共振「声部」，共振发生在网络之间而非铜块之上**（把块级感应机制原样升维）。
  - 声部单位 = **锈蚟级**（不是 BFS 连通块）；同锈蚟级的多个连通块出力**直接相加**。
  - 这点不只是简化，而是 `R ≤ 4` 封顶的**结构性前提**——否则玩家把同一锈蚟级拆成多个小簇即可刷 N，退化为 N×(N-1) 膨胀。
- 公式（各锈蚟级基础出力 `ema[k]`，k=0..3）：
  - `N = |{k : ema[k] > 0}| ∈ [1,4]`
  - `s = (Π Aₖ)^(1/N) ÷ (Σ Aₖ / N)`（几何平均 ÷ 算术平均，全部相等时=1）
  - `R = 1 + (N − 1) × s`，`R ∈ [1,4]`
  - **容器本 tick 总发电 = (Σ baseRe[k]) × R^exp，`exp` 先取 2（满共振 ×16），留作常量待实测调整**
- 铁律（安全性的核心）：
  - **共振只读「共振前」基础值，单遍前馈，绝不回代**——A 出力变大不得再回灌影响 A。
  - **每锈蚟级 EMA 只跟踪基础出力**，若吃乘过 R 的值会形成 `R↑→EMA↑→s变→R变` 回代环。
  - R 用平滑 EMA 计算（避免逐 tick 跳变导致闪烁），作用于本 tick 实际基础出力。
- 强度校准：满共振 ×16 看似激进，但**真正的成本大头是材料获取**——集齐 4 种锈蚀的涂蜡铜块需养蜂取蜜脾 + 逐级风化（时间门槛，逐级变慢）+ 逐级涂蜡收集，是递进式养成门槛而非重复建造成本；且「各网出力须平衡」意味着**共鸣上限被最稀有的氧化级卡住**，与 GM/AM 的短板效应一致。故超线性奖励（R²）对应超线性成本，合理。
- 待修文档问题：`docs/红电系统.md` §3.2（约第 600 行）表格仍写电力层锈蚟 =「耦合强度 强→弱（1.0/0.7/0.5/0.35）」，属 v17.1 过期文字。实际实现为二值网络隔离（代码 `LivingWaxedCopperFunction:278` `getOxidationLevel != genOxidation → continue`，`PowerMath` 无任何氧化级系数）。实现共振时需一并改写为新语义。

## 玩法洞察：集群涌现多相（n 可 >> 4）
- 用户实测：4 路红石输入经涂蜡铜块网络传播，检测 n=7，远超单块硬上限 4。定性为「真正的涌现」，正面态度。
- 机制：`runBfs` 从发电机 slot 扫描整个同锈蚀级铜块网络，每条 `(slot,dir)` 边一个独立 `SignalTracker`（edgeKey = slot<<2|dir）；红石传播延迟 + 网络拓扑让不同边在不同 tick 上升 → 不同相位 → 去重后 n 可远大于 4。
- 单块硬上限 n≤4（仅 4 个 dir）；集群打破上限 → 涌现的多相增益（eff_δ_sum / unlock 随 n 提升）。这正是「活物品网络」理念的副产品。
- 边界：若网络中多边同步上升（同 tick 相位相同），`deltaByOffset.merge` 合并 → n 塌成 1，无增益；真正增益需拓扑制造相位差。n=7 说明拓扑确实制造了 7 个不同相位。
- 可作活铜块网络玩法亮点（被动多相，玩家无需专门设计，搭够大网络自然多相）。
- 已落盘文档：① `docs/tech/living-power-tech.md` §3.3.1「网络涌现多相（n 可突破单块上限）」技术小节（机制 + 单块硬上限 4 + 同步塌缩边界）；② `docs/红电系统.md`「因子二：相位质量」小节末尾加玩家向「小知识 · 集群涌现多相」提示框。

## 文档补充：相位错开的真实来源（§3.3.1.1）
- 用户追问「铜块网络传播延迟如何产生」，经读码澄清并补文档。
- 关键澄清（易误导点）：铜块传播本身**无逐格延迟**——`phase2Propagation`（`ContainerRedstoneData.java:470`）是同 tick BFS，整个连通网络同一 tick 内走完。
- 真实错相来源两类：① 中继器档位延迟（`TICKS_PER_REPEATER_STEP=2`，`withDelayTimer(data.delay()*2)`，每红石刻=2 game tick）；② 各路输入的固有相位差（用户 4 路「间隔 0/1/2/3」本就错相）。
- 机制链：`runBfs` 每条 (slot,dir) 边独立记 `lastRisingTick`（全局 tick），`offset=lastRisingTick mod period`；两类来源叠加→不同 offset→去重后 n 增大。推论：纯铜块+同步输入+无中继器→全边同 tick 上升→n 塌缩为 1。
- 已落盘：`docs/tech/living-power-tech.md` §3.3.1 末尾新增 §3.3.1.1「相位错开的真实来源（先澄清一个误区）」（含误区框 + 两类来源 + 机制链 + 推论）。与 §3.3.1 文字「红石传播延迟」表述对齐，不再误导读者以为铜块逐格延。
