# 电力层改造：记账门控地基 + 相位解读三元件

## 设计定稿（两轮讨论结论）
- **地基**：记账跳变门控（已确认）——修复每 tick 无条件入账导致的中性化反转/谐波刷电/停机虚能量。
- **三变种 = 相位解读元件**（方案：移相/裂相/加法）：普通铜块退役为"纯基准"（只会读信号），三变种各自"解读"输入信号、派生新相位贡献给网络，丰富 n（解锁度 u = eff × n / pref 的平方奖励来源）：
  - **雕文 = 移相器**：读信号的"位置"——派生 (P, φ+1 mod P, δ)，可链式叠加成任意偏移延迟线（解锁奇数偏移制造，中继器延迟全是偶数 tick 造不出）；
  - **切制 = 裂相器**：读信号的"另一半"——下降沿反相解读，一个波形贡献 2 个反相相位；
  - **格栅 = 相位加法器**：读信号间的"关系"——同周期多路相位 mod P 求和派生新相位。
- 平衡红线：每个派生相位占一个真实元件槽位（"每条相线真实建造"演化为"每个派生相位真实占用"）；offset 去重天然防同相堆叠；n ≤ P 与解锁度公式不动；无数值倍率；派生事件走门控记账。分频中继延后再议（记入文档"后续设想"）。

## 阶段 A：记账跳变门控
1. `PhaseDomain` 增加「本 tick 跳变偏移集合」（`addOffset` 按 offset 去重记录）。
2. `ChannelState.bestActiveDomain(pref)`：只在本 tick 有跳变的域中按现有规则选最佳；无跳变 tick 返回 null。
3. `accountEnergy`：`re = 合因子 × P × 本tick跳变数`，读后清零；只记上升沿（文档"每周期 2 跳"的 ×2 常数折半，由 K=1/16 吸收）。
4. `copyFrom` 深拷贝携带跳变集合（锚点 BFS → 成员共享 → 各自入账后清零）。

## 阶段 B：拓扑统一 + 派生相位注册表（三元件共用基建）
1. TopoKey 坍缩为 `(oxidation)`：删除 axis/inEdge/outEdge 字段，`traversableNeighbor` 全向遍历，`repOf` 按锈级连通分量分组；删除 `channelSecondary`/`channel(axis)`/`topoKeysFor` 多通道机制，回归单通道（切制双通道退役）。
2. `ContainerPowerData` 新增派生相位注册表：`slot → List<DerivedPhase(period, offset, delta)>`，跨 tick 持久化（与 edgeTrackers 同生命周期）。
3. 每 tick 流程：① 组件 BFS 采样真实边 → tracker → 事件入通道，**并注入各访问槽位上 tick 的注册表条目**；② 相位解读 pass：各元件计算派生相位写注册表；③ accountEnergy（门控）。派生相位统一晚 1 tick 入账（offset 数学自洽：源上升于 t ≡ φ，派生上升于 t+1 ≡ φ+1）。
4. 组合与防环：相位元件可读取**输入方向邻居**的注册表条目作为输入（链式组合）；依赖关系每 tick 拓扑排序，成环元件本轮不产出且注册表清空（防止互相解读导致偏移自动跑满）。
5. 遥测：注册表条目进 F3+H 域快照。

## 阶段 C：雕文 = 移相器
1. 解读规则：读输入方向边的锁相相位 (P, φ, δ) → 派生 (P, (φ+1) mod P, δ)；同时读输入方向邻居的注册表条目 (P, φ′, δ′) → 派生 (P, (φ′+1) mod P, δ′)。k 台串联 = φ+k（WASD 箭头指向上游）。
2. `LivingWaxedChiseledData`：inputDir = 读取方向（WASD 保留 1 键），outputDir 退役（字段保留兼容、逻辑不再读取）。
3. 测试：φ→φ+1；3 链 → φ+3；P=4 从 offset 0 造出 {1,2,3} 满相 n=4；互指环不产出。

## 阶段 D：切制 = 裂相器
1. 下降沿跟踪：cut 槽位各边新增 falling `SignalTracker`（独立 edgeKey 命名空间），delta < 0 时喂入。
2. 解读规则：下降沿锁相相位 (P_f, φ_f, |Δ|) → 直接注册为派生相位（上升沿照常全网采样，无需派生）。
3. 涌现：非对称波形 φ_f ≠ φ+P/2；P=2 时钟 + 1 台切制 → n=2 满相（2t 满解锁从"几乎造不出"变为可达，多相门槛的进步性让位给更高 P 的制造链深度）。
4. 测试：方波 → {φ, φ_f} 两相；非对称钟的 φ_f 涌现；与移相链组合。

## 阶段 E：格栅 = 相位加法器
1. 解读规则：汇集 4 条边的真实同周期相位 + 四邻注册表条目，按周期分桶；对含 ≥2 个相位的桶派生 `(P, Σφᵢ mod P, min δᵢ)`。
2. 去重诚实：和已存在则无增益（addOffset 去重天然处理）；同相位双输入 → 2φ"翻倍"可算。
3. 数学结构（写入文档供探索）：可达相位 = 输入偏移生成的加法子群（如 {0,2} 在 P=8 下只能到 {0,2,4,6}），奇数偏移靠裂相或异形钟补足——三元件互补。
4. 测试：(2,3)→5 新相位；(0,2)→2 无增益；(1,1)→2；与移相链/裂相组合出满相。
