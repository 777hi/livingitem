## 痛点根因

核心问题是：**两个横切关注点被硬编码在了核心文件里**：

1. **容器级数据**（`ContainerRedstoneData`、`ContainerFluidData`、`ContainerStressData`）——每次都要在 `ContainerLivingItemHandler` 里加 `if` 分支 + 在 `TickContext` 里加字段
2. **WASD 朝向切换**——每次都要在 `LivingItemInputHandler` 里加 `isXxxItem()` + 在 `ServerPacketHandler` 里加 `else if`

## 方案：让 `LivingItemFunction` 接口声明能力

```java
// 活水桶、活水车、活红石 —— 需要容器级数据
public interface HasContainerData {
    Object createContainerData(int containerSize);
    void calculateContainerData(Object data, ContainerContext ctx, TickContext tick);
}

// 活漏斗、活熔炉、活火把 —— 支持 WASD 朝向
public interface HasDirection {
    boolean updateDirection(ItemStack stack, String slotName, Pos2D dir);
}
```

| 文件 | 改动 |
|------|------|
| `ContainerLivingItemHandler` | 遍历 grouped 时，检测 `HasContainerData`，自动创建+计算 |
| `TickContext` | 用一个 `Map<Class<?>, Object>` 代替逐个字段 |
| `LivingItemInputHandler` | 检测 `HasDirection`，自动处理 WASD |
| `ServerPacketHandler` | 检测 `HasDirection`，自动调用 `updateDirection` |
