### 1.4 Step 1：FluidAddress（复合地址）

**目的**：统一标识逻辑空间中的槽位——父容器直接槽位或活潜影箱内部槽位。

**文件**：`living/domain/redstone/FluidAddress.java`

```java
package com.qiqi.li.living.domain.redstone;

public record FluidAddress(int parentSlot, int slot) {
    public static final int PARENT_DIRECT = -1;

    public static FluidAddress direct(int slot) {
        return new FluidAddress(PARENT_DIRECT, slot);
    }

    public static FluidAddress inside(int parentSlot, int innerSlot) {
        return new FluidAddress(parentSlot, innerSlot);
    }

    public boolean isDirect() {
        return parentSlot == PARENT_DIRECT;
    }

    public long encode() {
        return ((long) (parentSlot + 1) << 32) | (slot & 0xFFFFFFFFL);
    }

    public static FluidAddress decode(long key) {
        int parent = (int) (key >>> 32) - 1;
        int slot = (int) key;
        return new FluidAddress(parent, slot);
    }
}
```

**用途**：`ContainerRedstoneData` 的 Map key 从 `int slot` 改为 `long key`（`FluidAddress.encode()`）。Phase 1 只用 `direct(slot)`，Phase 2 才用 `inside(parentSlot, innerSlot)`。

**验证**：`FluidAddress.direct(5).encode()` → decode → `FluidAddress(−1, 5)` ✓

### 1.5 Step 2：ContainerRedstoneData（信号传播核心）

**文件**：`living/domain/redstone/ContainerRedstoneData.java`

**设计**：参照 `ContainerFluidData` 的 BFS 模式，但信号衰减规则不同（红石每格 −1，最大 15）。

```java
package com.qiqi.li.living.domain.redstone;

import java.util.*;
import com.qiqi.li.living.container.ContainerContext;
import com.qiqi.li.living.api.LivingItemManager;

public class ContainerRedstoneData {

    public static final ContainerRedstoneData EMPTY = new ContainerRedstoneData();
    public static final int MAX_SIGNAL = 15;
    public static final int PROPAGATION_INTERVAL = 2;

    private final Map<Long, Integer> signalStrength = new LinkedHashMap<>();
    private final Set<Long> dirtySources = new LinkedHashSet<>();
    private RedstoneTopology topology;
    private int tickCounter;
    private boolean topologyDirty = true;

    public boolean isEmpty() { return signalStrength.isEmpty() && dirtySources.isEmpty(); }

    public int getSignal(long addrKey) {
        return signalStrength.getOrDefault(addrKey, 0);
    }

    public void setSourceSignal(long addrKey, int strength) {
        if (strength > 0) {
            signalStrength.put(addrKey, strength);
        } else {
            signalStrength.remove(addrKey);
        }
        dirtySources.add(addrKey);
    }

    public void markTopologyDirty() { topologyDirty = true; }

    public void tick(ContainerContext ctx) {
        tickCounter++;
        if (tickCounter % PROPAGATION_INTERVAL != 0) return;
        if (dirtySources.isEmpty() && !topologyDirty) return;

        if (topologyDirty) {
            topology = RedstoneTopology.build(ctx);
            topologyDirty = false;
        }

        propagate(ctx);
    }

    private void propagate(ContainerContext ctx) {
        Set<Long> wavefront = new LinkedHashSet<>(dirtySources);
        dirtySources.clear();

        while (!wavefront.isEmpty()) {
            Set<Long> nextWave = new LinkedHashSet<>();
            for (long addrKey : wavefront) {
                int newSignal = calculateSignal(addrKey);
                int oldSignal = signalStrength.getOrDefault(addrKey, 0);
                if (newSignal != oldSignal) {
                    if (newSignal > 0) signalStrength.put(addrKey, newSignal);
                    else signalStrength.remove(addrKey);
                    for (long neighbor : topology.getNeighbors(addrKey)) {
                        nextWave.add(neighbor);
                    }
                }
            }
            wavefront = nextWave;
        }
    }

    private int calculateSignal(long addrKey) {
        if (topology.isSource(addrKey)) {
            return signalStrength.getOrDefault(addrKey, 0);
        }
        int maxInput = 0;
        for (long neighbor : topology.getNeighbors(addrKey)) {
            int neighborSignal = signalStrength.getOrDefault(neighbor, 0);
            if (neighborSignal > 0) {
                maxInput = Math.max(maxInput, neighborSignal - 1);
            }
        }
        return Math.min(maxInput, MAX_SIGNAL);
    }
}
```

**与 ContainerFluidData 的关键差异**：

| | ContainerFluidData | ContainerRedstoneData |
|---|---|---|
| 衰减 | level + 1（水源=0，最远 7 格） | signal − 1（源=15，最远 15 格） |
| 传播间隔 | 4 tick | 2 tick（原版红石中继器 2 tick） |
| 阻挡 | 活物品阻挡 | 只有活红石组件参与传播 |
| 邻居 | `ContainerContext.getNeighbors()` | `RedstoneTopology.getNeighbors()`（只含红石组件） |

### 1.6 Step 2（续）：RedstoneTopology（连通分量 + 邻居缓存）

**文件**：`living/domain/redstone/RedstoneTopology.java`

```java
package com.qiqi.li.living.domain.redstone;

import java.util.*;
import com.qiqi.li.living.container.ContainerContext;
import com.qiqi.li.living.api.LivingItemManager;
import net.minecraft.world.item.ItemStack;

public class RedstoneTopology {
    private final Map<Long, long[]> neighborCache;
    private final Set<Long> sources;

    private RedstoneTopology(Map<Long, long[]> neighborCache, Set<Long> sources) {
        this.neighborCache = neighborCache;
        this.sources = sources;
    }

    public long[] getNeighbors(long addrKey) {
        return neighborCache.getOrDefault(addrKey, new long[0]);
    }

    public boolean isSource(long addrKey) {
        return sources.contains(addrKey);
    }

    public static RedstoneTopology build(ContainerContext ctx) {
        int size = ctx.getSize();
        int width = ctx.getWidth();
        Map<Long, long[]> cache = new LinkedHashMap<>();
        Set<Long> srcs = new LinkedHashSet<>();

        for (int i = 0; i < size; i++) {
            ItemStack stack = ctx.getItem(i);
            if (!isRedstoneComponent(stack)) continue;

            long addrKey = FluidAddress.direct(i).encode();

            if (isSignalSource(stack)) {
                srcs.add(addrKey);
            }

            int[] rawNeighbors = ContainerContext.getNeighbors(i, size, width);
            List<Long> redstoneNeighbors = new ArrayList<>();
            for (int n : rawNeighbors) {
                ItemStack neighborStack = ctx.getItem(n);
                if (isRedstoneComponent(neighborStack)) {
                    redstoneNeighbors.add(FluidAddress.direct(n).encode());
                }
            }
            cache.put(addrKey, redstoneNeighbors.stream().mapToLong(Long::longValue).toArray());
        }
        return new RedstoneTopology(cache, srcs);
    }

    private static boolean isRedstoneComponent(ItemStack stack) {
        if (!LivingItemManager.isLivingItem(stack)) return false;
        return stack.is(Items.REDSTONE)
            || stack.is(Items.REDSTONE_TORCH)
            || stack.is(Items.REPEATER)
            || stack.is(Items.COMPARATOR)
            || stack.is(Items.STONE_BUTTON) || stack.is(Items.OAK_BUTTON)
            || stack.is(Items.LEVER)
            || stack.is(Items.REDSTONE_LAMP);
    }

    private static boolean isSignalSource(ItemStack stack) {
        if (!LivingItemManager.isLivingItem(stack)) return false;
        return stack.is(Items.REDSTONE_TORCH)
            || stack.is(Items.STONE_BUTTON) || stack.is(Items.OAK_BUTTON)
            || stack.is(Items.LEVER);
    }
}
```

**验证**：3 个活红石粉排成一行，`build()` 产生 3 个条目，中间的邻居为 [左, 右]。

```java
public class LivingRedstoneFunction implements LivingItemFunction {
    public static final String ID = "living_redstone";

    @Override public boolean canApply(ItemStack stack) {
        return stack.is(Items.REDSTONE) && LivingItemManager.isLivingItem(stack);
    }
    @Override public String getFunctionId() { return ID; }

    @Override
    public void tick(List<SlotEntry> entries, ContainerContext ctx, TickContext tick, Level level) {
        if (level.isClientSide) return;
        // 活红石粉自身不产生信号，只传播

    public static void postTickSync(ContainerContext ctx, ContainerRedstoneData redstoneData,
                                     List<SlotEntry> entries) {
        for (SlotEntry entry : entries) {
            long addrKey = FluidAddress.direct(entry.slotIndex()).encode();
            int signal = redstoneData.getSignal(addrKey);
            LivingRedstoneData data = LivingItemManager.getRedstoneData(entry.stack());
            if (data.signalStrength() != signal) {
                LivingItemManager.setRedstoneData(entry.stack(), new LivingRedstoneData(signal));
                ctx.syncSlotToClients(entry.slotIndex(), entry.stack());
            }
        }
    }
}
```

```java
public class LivingRedstoneTorchFunction implements LivingItemFunction {
    public static final String ID = "living_redstone_torch";

    @Override public boolean canApply(ItemStack stack) {
        return stack.is(Items.REDSTONE_TORCH) && LivingItemManager.isLivingItem(stack);
    }
    @Override public String getFunctionId() { return ID; }

    @Override
    public void tick(List<SlotEntry> entries, ContainerContext ctx, TickContext tick, Level level) {
        if (level.isClientSide) return;
        ContainerRedstoneData redstoneData = tick.redstoneData;
        if (redstoneData == null) return;

        for (SlotEntry entry : entries) {
            long addrKey = FluidAddress.direct(entry.slotIndex()).encode();

            // 检查火把是否被邻居信号"关闭"（NOT 门逻辑）
            int maxInput = 0;
            int[] neighbors = ContainerContext.getNeighbors(
                entry.slotIndex(), ctx.getSize(), ctx.getWidth());
            for (int n : neighbors) {
                maxInput = Math.max(maxInput, redstoneData.getSignal(FluidAddress.direct(n).encode()));
            }

            boolean shouldBePowered = (maxInput == 0);
            LivingRedstoneTorchData data = LivingItemManager.getRedstoneTorchData(entry.stack());
            if (data.isPowered() != shouldBePowered) {
                LivingItemManager.setRedstoneTorchData(entry.stack(),
                    new LivingRedstoneTorchData(shouldBePowered));
                ctx.syncSlotToClients(entry.slotIndex(), entry.stack());
            }

            // 火把作为信号源：输出 15 或 0
            redstoneData.setSourceSignal(addrKey, shouldBePowered ? 15 : 0);
        }
    }

    public static void postTickSync(ContainerContext ctx, ContainerRedstoneData redstoneData,
                                     List<SlotEntry> entries) {
        // 信号已由 tick() 中 setSourceSignal 设置，无需额外同步
    }
}
```

### 2.4 Step 1：ShulkerLogicalSpace（核心）

**文件**：`living/container/ShulkerLogicalSpace.java`

**设计**：类大箱子原理——多个活潜影箱返回同一个逻辑视图。`addressMap` 将逻辑索引映射到物理地址（parentSlot + innerSlot），空洞位置为 null。

```java
package com.qiqi.li.living.container;

import java.util.*;
import com.qiqi.li.living.api.LivingItemManager;
import com.qiqi.li.living.domain.ender.LivingChestItemHandler;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.item.Items;

public class ShulkerLogicalSpace {
    private final int logicalWidth;
    private final int logicalHeight;
    private final PhysicalAddress[] addressMap;
    private final ContainerContext parentCtx;
    private final List<ShulkerRegion> regions;
    private final BoundaryBridgeMap bridges;

    public record PhysicalAddress(int parentSlot, int innerSlot) {}

    public record ShulkerRegion(
        int parentSlot,
        int logicalX, int logicalY,
        int width, int height
    ) {}

    public int getSize() { return logicalWidth * logicalHeight; }
    public int getWidth() { return logicalWidth; }
    public int getHeight() { return logicalHeight; }

    public PhysicalAddress getAddress(int logicalIndex) {
        if (logicalIndex < 0 || logicalIndex >= addressMap.length) return null;
        return addressMap[logicalIndex];
    }

    public ItemStack getItem(int logicalIndex) {
        PhysicalAddress addr = getAddress(logicalIndex);
        if (addr == null) return ItemStack.EMPTY;
        ItemStack shulkerStack = parentCtx.getItem(addr.parentSlot());
        return LivingChestItemHandler.getStackInSlot(shulkerStack, addr.innerSlot());
    }

    public void setItem(int logicalIndex, ItemStack stack) {
        PhysicalAddress addr = getAddress(logicalIndex);
        if (addr == null) return;
        ItemStack shulkerStack = parentCtx.getItem(addr.parentSlot());
        LivingChestItemHandler.setStackInSlot(shulkerStack, addr.innerSlot(), stack);
        parentCtx.syncSlotToClients(addr.parentSlot(), shulkerStack);
    }

    public int[] getNeighbors(int logicalIndex) {
        int x = logicalIndex % logicalWidth;
        int y = logicalIndex / logicalWidth;
        int count = 0;
        boolean left  = x > 0                && addressMap[logicalIndex - 1]            != null;
        boolean right = x + 1 < logicalWidth  && addressMap[logicalIndex + 1]            != null;
        boolean up    = y > 0                && addressMap[logicalIndex - logicalWidth]  != null;
        boolean down  = logicalIndex + logicalWidth < getSize()
                        && addressMap[logicalIndex + logicalWidth] != null;
        if (left)  count++;
        if (right) count++;
        if (up)    count++;
        if (down)  count++;
        int[] result = new int[count];
        int i = 0;
        if (left)  result[i++] = logicalIndex - 1;
        if (right) result[i++] = logicalIndex + 1;
        if (up)    result[i++] = logicalIndex - logicalWidth;
        if (down)  result[i++] = logicalIndex + logicalWidth;
        return result;
    }

    public BoundaryBridgeMap getBridges() { return bridges; }
    public List<ShulkerRegion> getRegions() { return regions; }

    public static ShulkerLogicalSpace build(ContainerContext parentCtx) {
        int parentWidth = parentCtx.getWidth();
        int parentSize = parentCtx.getSize();
        List<ShulkerRegion> regions = new ArrayList<>();
        for (int slot = 0; slot < parentSize; slot++) {
            ItemStack stack = parentCtx.getItem(slot);
            if (isLivingShulkerBox(stack)) {
                int col = slot % parentWidth;
                int row = slot / parentWidth;
                regions.add(new ShulkerRegion(slot, col * 9, row * 3, 9, 3));
            }
        }
        if (regions.isEmpty()) return null;

        int minX = regions.stream().mapToInt(ShulkerRegion::logicalX).min().orElse(0);
        int minY = regions.stream().mapToInt(ShulkerRegion::logicalY).min().orElse(0);
        int maxX = regions.stream().mapToInt(r -> r.logicalX + r.width).max().orElse(0);
        int maxY = regions.stream().mapToInt(r -> r.logicalY + r.height).max().orElse(0);

        int logicalWidth = maxX - minX;
        int logicalHeight = maxY - minY;

        PhysicalAddress[] addressMap = new PhysicalAddress[logicalWidth * logicalHeight];
        for (ShulkerRegion region : regions) {
            for (int dy = 0; dy < region.height; dy++) {
                for (int dx = 0; dx < region.width; dx++) {
                    int lx = region.logicalX - minX + dx;
                    int ly = region.logicalY - minY + dy;
                    int li = ly * logicalWidth + lx;
                    int innerSlot = dy * 9 + dx;
                    addressMap[li] = new PhysicalAddress(region.parentSlot, innerSlot);
                }
            }
        }

        BoundaryBridgeMap bridges = BoundaryBridgeMap.build(
            parentCtx, regions, minX, minY, logicalWidth);
        return new ShulkerLogicalSpace(logicalWidth, logicalHeight, addressMap,
                                        parentCtx, regions, bridges);
    }

    private static boolean isLivingShulkerBox(ItemStack stack) {
        return stack.is(Items.SHULKER_BOX) && LivingItemManager.isLivingItem(stack);
    }
}
```

**关键设计决策**：
- `addressMap` 是扁平数组，O(1) 查找
- 空洞位置（非活潜影箱覆盖的区域）为 null，`getItem` 返回 `ItemStack.EMPTY`
- `getNeighbors` 跳过 null 空洞，只返回有效邻居
- `build()` 每次调用重新构建，通过 `TickContext` 缓存避免重复

**验证**：2 个水平相邻活潜影箱 → `logicalWidth=18, logicalHeight=3, getSize()=54`。

### 2.5 Step 2：BoundaryBridgeMap（边界桥接表）

**文件**：`living/container/BoundaryBridgeMap.java`

```java
package com.qiqi.li.living.container;

import java.util.*;
import com.qiqi.li.living.model.Pos2D;

public class BoundaryBridgeMap {
    public record Bridge(
        int fromParent, int fromInner,
        int toParent, int toInner,
        Pos2D direction
    ) {}

    private final Map<Long, Bridge> bridgeMap;

    private BoundaryBridgeMap(Map<Long, Bridge> bridgeMap) {
        this.bridgeMap = bridgeMap;
    }

    private static long key(int parent, int inner) {
        return ((long) parent << 32) | (inner & 0xFFFFFFFFL);
    }

    public Bridge getBridge(int parentSlot, int innerSlot) {
        return bridgeMap.get(key(parentSlot, innerSlot));
    }

    public static BoundaryBridgeMap build(ContainerContext ctx, List<ShulkerLogicalSpace.ShulkerRegion> regions,
                                            int minX, int minY, int logicalWidth) {
        Map<Long, Bridge> map = new LinkedHashMap<>();
        int parentWidth = ctx.getWidth();

        for (int i = 0; i < regions.size(); i++) {
            var a = regions.get(i);
            int aCol = a.parentSlot() % parentWidth;
            int aRow = a.parentSlot() / parentWidth;

            for (int j = 0; j < regions.size(); j++) {
                if (i == j) continue;
                var b = regions.get(j);
                int bCol = b.parentSlot() % parentWidth;
                int bRow = b.parentSlot() / parentWidth;

                if (bCol == aCol + 1 && bRow == aRow) {
                    for (int r = 0; r < 3; r++) {
                        map.put(key(a.parentSlot(), 8 + r * 9),
                            new Bridge(a.parentSlot(), 8 + r * 9, b.parentSlot(), 0 + r * 9, Pos2D.RIGHT));
                        map.put(key(b.parentSlot(), 0 + r * 9),
                            new Bridge(b.parentSlot(), 0 + r * 9, a.parentSlot(), 8 + r * 9, Pos2D.LEFT));
                    }
                }
                if (bRow == aRow + 1 && bCol == aCol) {
                    for (int c = 0; c < 9; c++) {
                        map.put(key(a.parentSlot(), 18 + c),
                            new Bridge(a.parentSlot(), 18 + c, b.parentSlot(), c, Pos2D.DOWN));
                        map.put(key(b.parentSlot(), c),
                            new Bridge(b.parentSlot(), c, a.parentSlot(), 18 + c, Pos2D.UP));
                    }
                }
            }
        }
        return new BoundaryBridgeMap(map);
    }
}
```

**验证**：A(parentSlot=0) 右邻 B(parentSlot=1) → `getBridge(0, 8)` = Bridge(0,8 → 1,0, RIGHT) ✓

### 2.6 Step 3：ExtendedSlotResolver（扩展槽位解析）

**文件**：`living/transfer/ExtendedSlotResolver.java`

```java
package com.qiqi.li.living.transfer;

import com.qiqi.li.living.container.BoundaryBridgeMap;
import com.qiqi.li.living.model.Pos2D;

public final class ExtendedSlotResolver {
    public static final int INVALID = -1;
    public static final int SHULKER_WIDTH = 9;
    public static final int SHULKER_HEIGHT = 3;

    public record ResolvedAddress(int parentSlot, int innerSlot, boolean crossedBoundary) {}

    public static ResolvedAddress resolve(
        int parentSlot, int innerSlot, Pos2D direction, BoundaryBridgeMap bridges
    ) {
        int col = innerSlot % SHULKER_WIDTH;
        int row = innerSlot / SHULKER_WIDTH;
        int newCol = col + direction.x();
        int newRow = row + direction.y();

        if (newCol >= 0 && newCol < SHULKER_WIDTH
            && newRow >= 0 && newRow < SHULKER_HEIGHT) {
            return new ResolvedAddress(parentSlot, newRow * SHULKER_WIDTH + newCol, false);
        }

        BoundaryBridgeMap.Bridge bridge = bridges.getBridge(parentSlot, innerSlot);
        if (bridge != null && bridge.direction().equals(direction)) {
            return new ResolvedAddress(bridge.toParent(), bridge.toInner(), true);
        }

        return new ResolvedAddress(INVALID, INVALID, false);
    }
}
```

- 从 A 内部 (1,1) 向右 → A 内部 (2,1)，`crossedBoundary=false`
- 从 A 内部 (8,1) 向右 → B 内部 (0,1)，`crossedBoundary=true`

#### CopperWireNetwork（无衰减导线网络）

```java
package com.qiqi.li.living.domain.redelectric;

import java.util.*;
import it.unimi.dsi.fastutil.longs.Long2IntMap;
import it.unimi.dsi.fastutil.longs.Long2IntOpenHashMap;
import it.unimi.dsi.fastutil.longs.LongSet;

public class CopperWireNetwork {
    private final List<LongSet> components = new ArrayList<>();
    private final Long2IntMap componentOf = new Long2IntOpenHashMap();
    private final List<Long> componentEnergy = new ArrayList<>();

    public long getEnergy(long addrKey) {
        int compIdx = componentOf.getOrDefault(addrKey, -1);
        if (compIdx < 0 || compIdx >= componentEnergy.size()) return 0;
        return componentEnergy.get(compIdx);
    }

    public void addEnergy(long addrKey, long amount) {
        int compIdx = componentOf.getOrDefault(addrKey, -1);
        if (compIdx < 0) return;
        componentEnergy.set(compIdx, componentEnergy.get(compIdx) + amount);
    }

    // build(): Union-Find 划分连通分量
    public static CopperWireNetwork build(ContainerContext ctx) { ... }
}
```

#### RedElectricWave（红电波）

```java
package com.qiqi.li.living.domain.redelectric;

public class RedElectricWave {
    private final int frequency;       // tick/周期
    private final int amplitude;       // 0-15
    private final long sourceAddr;     // 发射源地址
    private final long emitTick;       // 发射时刻

    public int getSignalAt(long targetAddr, long currentTick, double distance) {
        long elapsed = currentTick - emitTick;
        if (elapsed < 0) return 0;
        double attenuation = 1.0 / (1.0 + distance * distance);
        return (int) (amplitude * attenuation);
    }
}
```

#### ChannelRegistry（频率复用）

```java
package com.qiqi.li.living.domain.redelectric;

import java.util.*;

public class ChannelRegistry {
    private final Map<Integer, List<RedElectricWave>> channels = new LinkedHashMap<>();
    private final Map<Integer, List<Long>> receivers = new LinkedHashMap<>();

    public void emit(int frequency, RedElectricWave wave) {
        channels.computeIfAbsent(frequency, k -> new ArrayList<>()).add(wave);
    }

    public int receive(long receiverAddr, int tunedFrequency, long currentTick) {
        List<RedElectricWave> waves = channels.get(tunedFrequency);
        if (waves == null) return 0;
        int maxSignal = 0;
        for (RedElectricWave wave : waves) {
            double distance = calculateDistance(wave.sourceAddr(), receiverAddr);
            int signal = wave.getSignalAt(receiverAddr, currentTick, distance);
            maxSignal = Math.max(maxSignal, signal);
        }
        return maxSignal;
    }
}
```

#### 红电转换公式

```
红→电：power = k × signal²    （P = V²/R，信号强度类比电压）
电→红：signal = √(power / k)  （反向转换）
k = 1（简化，1 信号强度 = 1 FE）
```
