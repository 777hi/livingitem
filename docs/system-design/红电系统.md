关于红电系统的一些定义：
活铜块们接触到红石信号会产生红电信号，红电信号传输到活红石原件里又会变为红石信号，红石信号和红电信号都是信号。
两种信号在不同介质里传播时会有不同的一些性质。
红石信号和红电信号可以灵活的互相转换，称为”红电转换“。
活涂蜡铜块们接触到红石信号和红电信号不会产生信号，但是接触到有一定规律的变化信号时，会产生红电。这种通过信号产生红电的方式，称为“红电效应”。

## 0. 总览

三大系统的关系：

```
活红石   ──→ 逻辑层（信号 0-15，门电路，时序电路）
活铜块   ──→ 信号层（未涂蜡：频道隔离 + 5 种拓扑）
             电力层（涂蜡：感应发电 + 储能）
活避雷针 ──→ 传输层（红电波频道，跨容器/跨维度）【规划，未实现】

活红石 + 活铜块 = 电气系统（信号同源，涂蜡分层）
活铜块 + 活避雷针 = 无线电力网络（局域发电 + 全局供需分配）【规划】
三者合一 = 信息时代（计算 + 电力 + 无线传输）【规划】
```

**核心设计**：红石信号与红电信号**本质同源**，只是在不同介质中的叫法不同——
无需任何转换器物品。铜块**涂蜡与否**决定它工作在信号层还是电力层。

实施顺序：**活红石 → 活铜块 → 活避雷针**。前两者已实现且各自可用，组合后形成完整电气系统；
活避雷针与信息时代为未来规划（见 [buffer §6](../buffer/redstone-evolution-roadmap.md)）。

> 活潜影箱（封装层）已从本系统剥离——它是独立于红电的**通用活物品基础设施**
> （兼容所有活物品的嵌套容器），设计详见 [活潜影箱实现细节.md](../buffer/活潜影箱实现细节.md)。

## 3. 活铜块（信号介质 + 电力系统）

### 3.1 核心概念：红石信号与红电信号同源

**红石信号和红电信号本质是同一种信号，只是在不同介质中的叫法不同。**

```
信号在活红石元件中传播  → 称为「红石信号」
信号在活铜块家族中传播  → 称为「红电信号」

两者自由互转，无需任何转换器物品：
  活红石粉 → 活铜块   ：红石信号变为红电信号
  活铜块 → 活红石粉   ：红电信号变为红石信号
```

活铜块家族的传播行为与活红石粉一致（同一 BFS 队列），
但**衰减口径不同**：红石粉只在「粉 → 粉」这一跳减 1（对其它元件按自身强度输出），
活铜块家族转发**完全无损**；区别在于**铜块提供了红石粉没有的拓扑能力**（见 §3.3）。

### 3.2 三轴正交模型

原版铜块相关物品有 5 种形态 × 4 档锈蚀 × 2 种涂蜡 = 40 件。
若逐个设计机制则无人能记住，因此采用**三轴正交**：每个轴只管一件事。

| 轴        | 控制               | 取值                     |
| -------- | ---------------- | ---------------------- |
| **基础形态** | 拓扑（信号怎么流 / 感应什么） | 铜块 / 雕文 / 切制 / 格栅 / 铜灯 |
| **锈蚀状态** | 分档（信号层=频道，电力层=共振锈级） | 未锈蚀 / 斑驳 / 风化 / 氧化     |
| **涂蜡**   | 层次（信号层 / 电力层）    | 未涂蜡 = 导电传信号，涂蜡 = 绝缘产电力 |

只需掌握 **5 + 4 + 2 = 11 个概念**，即可推断全部 40 件物品的行为。

> 例：`涂蜡风化切制铜块` 堆叠 8 = 电力层 + 第 3 锈级 + 十字拓扑（两轴感应）
> → 偏好周期 = 8 tick（= 堆叠数），读取两个轴向的相位差发电。看名字即知拓扑，堆叠数即知谐振点。

#### 锈蚀 = 分档（两层各有含义）

锈蚀在两层都表示「第几档」，但档位的**含义**随层次而变：

| 层次 | 锈蚀的含义 | 未锈蚀 → 氧化 |
| -- | ----- | --------- |
| 信号层（未涂蜡） | **频道**：不同档位互不导通 | A / B / C / D 四条独立线路 |
| 电力层（涂蜡） | **共振锈级**：跨锈级共振的对象 | 第 1 / 2 / 3 / 4 锈级 |

两层的档位序号一致，只是一个管「跟谁连」（频道），一个管「跟谁共振」（锈级）——
都是「第几档 / 第几路」的寻址语义，区别只在于被寻址的对象是信号还是网络。
之所以能这样分工，是因为**涂蜡铜块本来就不导通**——
既然它不参与连线，「频道」对它就没有意义，档位自然腾出来表达别的东西。

> ⚠️ **旧版（v17.1）曾把电力层锈蚀定义为「耦合强度管径 1.0 / 0.7 / 0.5 / 0.35」**，
> 该设计已在 v17.7 移除（`PowerMath` 与 `LivingWaxedCopperFunction` 中不存在任何
> 氧化级系数）。电力层锈蚀现在是**二值网络隔离 + 跨级共振**，
> 氧化级高**不会**降低发电效率，只会让你处在另一个网络（另一个锈级）里。

##### 信号层：锈蚀 = 频道隔离

不同锈蚀状态的活铜块之间**不传递红电信号**，等同于相互绝缘的独立导线。

```
[未锈蚀铜块] ─✅→ [未锈蚀铜块]     同频道，导通
[未锈蚀铜块] ─✗→ [斑驳铜块]       不同频道，绝缘
[活红石粉]   ─✅→ [任意锈蚀铜块]   红石粉可注入任意频道
```

**这是 2D 布线的核心价值**：9×6 网格中，4 种锈蚀铜块 + 活红石粉
可以走 5 路互不干扰的独立信号。原版红石粉相邻必然串信号，
在 2D 平面上几乎无法布线。

##### 电力层：锈蚀 = 共振锈级（网络隔离 + 跨级共振）

见 [§3.5 铜块网络传播](#35-铜块网络传播设计) 与 [§3.6.1 网络级共振](#361-网络级共振设计)。
发电机通过按网络组件遍历同氧化等级铜块网络检测边信号（每组件仅锚点跑一次 BFS，其余 copyFrom 共享相位历史）。
不同锈蚀等级（新鲜/暴露/锈蚀/氧化）形成 4 个独立网络，互不连通。

**隔离只是手段，共振才是目的**：每个锈蚀级是一个「锈级」，多个锈蚀级同时发电时
按**出力平衡度**互相感应（共振）——出力越接近、锈级越多，总发电量越高
（满配 ×16）。只建一种锈蚀级 = 只有一个锈级 = 没有共振加成。

锈级的共振单位是**锈蚀级**而非 BFS 连通块：同锈蚀级的多个互不相连的连通块出力直接相加。
这既是简化，也是共振倍率上限被封死在 4 的结构性前提（否则拆簇即可刷倍率）。
储能侧同样按锈级对齐——k 锈级发电只入 k 锈级铜灯（[§3.6 锈级专属通道](#36-储能设计)）。

#### 涂蜡 = 层次切换

蜡是绝缘体，因此**涂蜡铜块不传导信号**——但它能通过同氧化等级网络传播相位事件。

```
未涂蜡：导电 → 传播红电信号（信号层）
涂蜡  ：绝缘 → 通过网络传播相位事件并发电（电力层）
```

### 3.3 信号层：五种形态的拓扑能力

未涂蜡的活铜块家族在信号层工作，每种形态提供一种红石粉做不到的拓扑能力。

#### 铜块 = 电缆

全向连接同频道邻居，行为等同活红石粉，但**受锈蚀频道隔离**。
电力网络与信号网络的默认连接件。

```
     ┌──→ 邻居(同锈蚀)
     │
邻居 ←── [铜块] ──→ 邻居(同锈蚀)
     │
     └──→ 邻居(同锈蚀)
```

#### 切制铜块 = 立交桥（Crossover）

解决 2D 网格中两路信号交叉的问题。**水平轴与垂直轴完全独立**，交叉点互不干扰。

```
    信号A ──→ ┃          ┃ ──→ 信号A（水平直通）
               ┃ 切制铜块 ┃
    信号B ──→ ┃    ╳    ┃ ──→ 信号B（垂直直通）
               ┃          ┃
              A 与 B 交叉但绝缘
```

配合锈蚀频道，这是 2D 布线的最后一块拼图：
即使同频道的两路信号也能交叉而不串扰。

> 实现提示：现有 `EdgeGrid` 将信号存在**边**上（`hEdges` / `vEdges`），
> 水平边与垂直边天然分离，切制铜块的立交桥语义可直接落地。

#### 雕文铜块 = 二极管（输入/输出双方向）

输入/输出方向独立设置，信号仅从输入方向接收、仅向输出方向转发。通过 WASD 2 键配置：第 1 键设输入方向，第 2 键设输出方向。默认输入=↓ 输出=↑（下传上）。

```
    输入=↓ 输出=↑  →  下传上（默认）
    输入=← 输出=→  →  左传右
    输入=← 输出=↑  →  左传上（拐角导通）
    输入=↓ 输出=→  →  下传右（拐角导通）
```

原版中"防止信号回流"由中继器承担，但中继器占格子且有 2 tick 延迟。
雕文铜块提供**零延迟定向导通**，且支持拐角，是 2D 布线的关键器件。

| <br /> | 活中继器     | 雕文铜块       |
| ------ | -------- | ---------- |
| 单向     | ✅        | ✅          |
| 拐角     | ❌        | ✅          |
| 延迟     | 2-8 tick | **0 tick** |
| 信号刷新   | ✅ 恢复到 15 | ✗ 继续衰减     |
| 用途     | 延迟 + 整形  | 纯防回流 + 拐角  |

#### 铜格栅 = 红石→红电桥接加法器

格栅有孔 = 红石信号穿过孔洞汇入铜网络。所有输入边的红石信号**相加**，
结果向四周同锈蚀状态的铜原件输出。

```
红石信号A ──→ ┐
              ├── [铜格栅] ──→ 铜电缆（同锈蚀）
红石信号B ──→ ┘
        sumSignal = min(A + B, signalCap)
```

- **输入**：只接收红石信号（红石粉、红石块、火把等），不接收铜电缆信号
- **求和**：4条边的红石信号相加，受 signalCap 上限
- **输出**：向4方向输出到同锈蚀状态的铜原件
- **隔离**：铜→格栅方向阻断，防止铜信号回灌

用途：将红石电路的信号桥接到铜电缆网络，同时实现多路信号合并。

#### 铜灯 = 信号记忆（记录/清除）

活铜灯收到红石信号上升沿时记录该信号强度，再次收到上升沿时熄灭清除记录。
记录的信号强度可被活比较器的比较模式读取。

```
收到上升沿 → 若未记录：记录输入信号强度
           → 若已记录：熄灭清除
无输入     → 保持当前记录
```

这是未来「信息时代」的基础：信号强度存储、锁存器、寄存器均依赖它。
没有记忆单元，容器内只能实现组合逻辑，无法实现时序逻辑。

#### 信号层能力对照

| 形态 | 拓扑能力       | 对应原版/电子学        |
| -- | ---------- | --------------- |
| 铜块 | 全向传导（频道隔离） | 电缆              |
| 切制 | 双轴独立交叉     | 立交桥 / Crossover |
| 雕文 | 输入/输出双方向   | 二极管（可拐角）       |
| 格栅 | 红石→红电桥接加法 | 加法器             |

### 3.4 电力层：感应发电模型（设计）

> **公式链与计算表见 [power-tech §3.4 / §9](../tech/living-power-tech.md)**，本节只留设计立意与"为什么"。

**设计立意**：产量取决于信号布局的精密程度，而非燃料投入——
与「烧资源发电」的科技模组相反，红电以布局技巧决定产出。
设计哲学：**以少量规则让行为由组合涌现**——
系统里没有需要查表的硬设定，只有可推理的机制。

涂蜡铜块对周围红电信号的**变化**产生感应，从而在内部产生红电（FE）。
两个因子各管一件事，每一步都是**正向增长**（只有奖励，没有惩罚）：
幅度看信号源，相位质量看布局（n）与调谐（u）。
**发电机堆叠数 = 偏好周期 = stackCount（2~64 tick）**是调谐参数；
**信号源堆叠数决定幅度**（信号值 = 源 stackCount²）。

#### 为什么要有 ×P（频率中性化）

`单次跳变能量(RE) = 合因子 × P`。方波周期 P 每周期跳 2 次（每 tick 跳 2/P 次），
平均功率 = (合因子 × P) × (2/P) = 2 × 合因子——**P 被完全消掉**。
×P 用来抵消「快时钟跳得密」：2t 时钟跳得密、64t 时钟单次多，两边打平。
**低周期不是捷径，而是更多的选择**——频率选择完全由「你造得出什么时钟」和「匹配得多准」决定。
若无 ×P，快时钟平均功率碾压慢时钟 32 倍。

#### 为什么乘 K = 1/16

K 是**边界换算常量**，只出现在电池 / IEnergyStorage 输出处（`FE = RE × K`）。
内部记账用自然单位 **RE**（`每跳能量(RE) = 合因子 × P`，全是涌现量）；
K 对所有发电机一视同仁地缩放，不改变相对强弱。
**不要把 K 绑到最大周期等设计参数上**——那会让改动堆叠数隐式重标定整个能源经济。

#### 因子一：基础幅度（门槛）

**只有交变信号才发电**，恒定信号不发电（`|Δsignal| = |signal_now - signal_prev|`，直流 Δ=0）。
因此须以振荡器产生交变信号（最简为中继器环形回路）。

> ⚠️ **`signal_prev` 必须按槽位存储，不能存在物品 DataComponent 上。**
> 否则拖动涂蜡铜块到不同信号环境的槽位就能凭空制造 Δ，形成永动机。
> 复用 `ContainerRedstoneData.prevEdgeGrid` 双缓冲提供的按槽位历史值。

#### 因子二：相位质量（布局 × 调谐，平方奖励）

多路输入的相位错开数 n 与解锁度 u 决定平方奖励：`合因子 = (eff_δ_sum)^(1+u)`，
u=0（失谐/宽带）→ 线性下限，u=1（完美调谐 + n=偏好周期）→ 平方上限。
**堆 1 叠 = 宽带接收器**（效率固定 0）：不调谐也有保底产出，并可利用混合周期杂讯。

- **同相输入合并计数**（不奖励也不惩罚），不是归零——两个相同振荡器并排应当有产出。
- **集群涌现多相**：n 统计「网络里被充能的边数」，不是接的红石路数；网络越大参与相位的边越多，
  少数红石输入经网络传播自然涌现多相。单块仅 4 条边（n≤4），**多相须靠网络集群**。
- **「错开」的精确定义**：相位只在同周期路径间比较（按周期分域，相数不跨域累加）；
  相位 = 周期内整数 tick 偏移，≥1 tick 才算两相（整数 tick 既是分辨率下限，也是 n≤P 的来源）；
  同相合并为一组。180°/120°/90° 是标准满相摆法而非判定条件。

#### 本地感应：共享感知，分别发电

不引入「集群」实体，规则为：**相邻块共享输入路数和信号（经铜块网络逐跳转发），发电计算逐块独立。**
路 = 物理信号路径，**n ≤ min(路径数, P)**——每条相线都要真实建造，槽位是自然约束；
N 块 = N 份线性叠加（铜块是成本而非放大器）。满相协作门槛：k 块直排提供 2k+2 个外部边位，
吃满 P 相需 2k+2 ≥ P 且块间连通。

#### 调谐敏感性与相数上限（自然涌现的取舍）

同样差 1 tick，偏好周期越大越无损（64t 差 1 tick ≈ 99.5% 效率，2t 差 1 tick = 180° = 0%）——
由 `(1+cosθ)/2` 自然得出：大偏好周期调谐容错高，小偏好周期须精确到单 tick；
失谐最坏仅「平方退化为线性」，无颗粒无收的悬崖。整数 tick 又决定最大相数 ≤ P：
**高频少相**（省槽位、零容错）vs **低频多相**（容错高、需占满容器）vs 中频中相——
没有唯一最优解，取舍从「整数 tick」约束推导而来，非人为设定。

#### 形态 = 相位解读（v19.1：从「听什么」到「造什么」）

普通铜块 = 基准（只读不造）；三形态各自「解读」输入信号、派生新相位贡献给网络，
每个派生相位占一个真实元件槽位，n ≤ P 与解锁度公式不动，无数值倍率：

| 形态 | 解读 | 规则 |
|---|---|---|
| 涂蜡铜块 | —（纯基准） | 只读不造；网络连通性唯一维度 = 氧化等级 |
| 涂蜡雕文 | 信号的「位置」 | 移相器：派生 (P, φ+1 mod P, δ)；链式已暂时关闭（2026-09-08，凑满相超模） |
| 涂蜡切制 | 信号的「另一半」 | 裂相器：下降沿登记为派生相位（一个方波 2 个反相相位） |
| 涂蜡格栅 | 信号间的「关系」 | 加法器：同周期 ≥2 路派生 (P, Σφᵢ mod P, min δᵢ) |

去重诚实（同 offset 合并不虚增 n）、死源熄灭（停跳超存活窗口修剪，不永动）。
实现与测试见 [power-tech §3.8](../tech/living-power-tech.md)。

#### 设计原则：让玩家「算」，不让玩家「查」

| 机制 | 判定 | 理由 |
| ------------- | ---- | ------------------------ |
| 相位差 120° | ✅ 采纳 | 玩家能算：周期 6，延迟 0/2/4 |
| 共振匹配偏好周期 | ✅ 采纳 | 玩家能算：周期 6 的时钟堆 6 叠恰好谐振 |
| 氧化等级网络隔离 | ✅ 采纳 | 玩家能算：不同氧化等级独立网络 |
| 铜块网络传播（按组件遍历） | ✅ 采纳 | 玩家能记：同氧化等级铜块连通，铜灯不导电 |
| 谐振频率 = 电路铜块总数 | ❌ 否决 | 多铺一根电缆就破坏谐振，不可预测 |
| 起振时间 / Q 值 | ❌ 否决 | 不可观测，拉长调试反馈周期 |
| 阻抗匹配 | ❌ 否决 | 用电侧是外部模组机器，玩家只能查表 |

### 3.5 铜块网络传播（设计）

> 实现见 [power-tech §3.1 / §5](../tech/living-power-tech.md)。

涂蜡铜块是绝缘的，但**同氧化等级的相邻铜块之间可以传播相位事件**。
发电机遍历同氧化等级铜块网络检测振荡器信号，不同锈蚀等级形成彼此隔离的网络
（铜灯不参与传播，仅储能）。

**设计意义**：① >4 相输入——振荡器不必紧贴发电机，经网络延伸接入更多振荡器；
② 布线需求——不同氧化等级网络隔离需规划拓扑；③ 建造复杂度——网络越长铺铜越多，自然约束；
④ 无距离衰减——网络内传播无距离约束，但氧化等级隔离是硬约束。

### 3.6 储能（设计）

> 实现与容量标定见 [power-tech §4](../tech/living-power-tech.md)。

**无容器池**：发电直接按剩余容量比例存入**同锈级**铜灯堆；无同锈级灯时电凭空消失——
发电必须被消费或储存，这是电力层的即时结算约束，也是涂蜡铜灯存在意义的根基。

**涂蜡铜灯 = 纯粹容器**：无充放限率，只管装；限流职责归用电侧。

- **容量线性**（每盏 C × count）：平方容量在拆分时坍缩毁电，弃用；线性下任何拆分/搬运/合并严格守恒。
- **电量按盏存是防止凭空产能的根基**：拆分时组件被复制，按盏存则 64×q 拆成 54+10 各带 q，天然守恒；
  合并由原版「组件相同才堆叠」语义免费保护。
- **堆叠价值 = 格位效率**：64 盏一条格子 vs 占 64 格。
- 池常态为空（每 tick 结算清空）→ 无需容器级持久化，电全住在铜灯 DataComponent 随 NBT 走。

**锈级专属通道（v18）**：k 锈级灯只接收 k 锈级网络的发电（含共振增益），即锈级一一对应。
共振增益按锈级纯度归属（`voiceRe[k] = round(baseReByOx[k] × gain)`）；平衡度 s 只看发电侧，配错灯不毁共振。
设计意义：共振增益按锈级归属（各锈级灯亮度 = 共振进度可视化）；四锈级灯成第二道材料门槛；
发电配线与储能配线成两个独立维度（各有短板）；世界观自洽（灯不导电只储能 → 专属通道是定义的自然推论）。

**通用电池哲学（无出身论）**：仅已活化的涂蜡铜灯提供 `EnergyStorage.ITEM` 能力，双向开放（放电/充电）。
外部充的电与红电发的电在灯里混为一个 q、不分来源——电一旦存进灯就是通用 FE。
隔离只发生在「发电 → 充电」这一跳（红电效应产物回流路径），出口与外来入口无锈级限制。
跨系统能量等量转换，守恒无套利。

### 3.6.1 网络级共振（设计）

> 公式推导与场景测试见 [power-tech §3.7](../tech/living-power-tech.md)。本节只留设计结论。

**核心思路**：把对象从「单个涂蜡铜块」抬到「锈蚀级发电网络」维度。
同锈级若干连通块出力**直接相加**（锈级 = 共振单位，不是 BFS 连通块），
不同锈级之间按**出力平衡度**互相感应（共振），无需物理接触（各锈级天然共处同一容器）。
满配 4 锈级且出力完全平衡时总发电 ×16。

**三条铁律（安全红线）**：① 只读基础值、单遍前馈（增益绝不回灌，杜绝永动）；
② EMA 只跟踪基础出力；③ EMA 必须截断归零（否则停发锈级永远顶「活跃」名分把 s 永久压死）。
平衡度 s 与增益 gain 只看发电侧——铜灯怎么配完全不影响共振计算。

**设计校准**：s 用 GM/AM 而非方差（规模无关，引导追求规模相近而非单纯堆量；凑弱网稀释平衡度反而降低收益）；
×16 超线性回报匹配 4 锈级铜块的超线性获取成本（养蜂取蜜蜡 + 逐级风化 + 每级涂蜡）。

**设计原则：只实现 FE，其余单位由枢纽桥接**——Mekanism 通用电缆内置几乎所有主流电力单位转换，

**边界契约（相位稳定性）**：我方保证「信号一旦进入活红石网络（含由活红石元件产生），
其相位跨会话稳定」；第三方模组红石元件作为跨容器信号源时，其重进相位漂移属上游 mod 重建行为，
非我方缺陷（无 API 可介入）——此场景应改用活红石元件搭振荡源。

| `HasDirection`                       | 切制铜块条纹方向、雕文输入/输出朝向配置                            |
| `ContainerContext` + `Pos2D`         | 信号传播的 2D 空间模型                                   |
| **`ContainerRedstoneData.EdgeGrid`** | **铜块信号直接复用边存储；`prevEdgeGrid` 提供 Δ 计算所需历史值** |
| `TickContext`                        | 红石信号数据和电力数据挂在此处                                 |
| `DataComponent` 体系                   | 所有新活物品的数据组件                                     |
| `IEnergyStorage`                     | 活铜块电力系统对外暴露接口                                   |
| `ServerStoppedEvent` 清理              | 进程级静态表（如未来 `RedElectricWaveRegistry`）必须接入        |
| 单元测试基建                               | 相位/频率计算是纯逻辑，比照 `ContainerRedstoneDataTest` 覆盖  |
