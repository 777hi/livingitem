## 活耕地设计（原始创意笔记，已转化）

### 概念
活耕地在容器中自动种植和收获作物。玩家将种子「种」到活耕地上（仅作类型标记，**不消耗种子**），
活耕地推进生长进度、成熟后逐项产出到生长槽位。

### 原始创意要点（详见技术文档）

- **获取**：活锄头右键活泥土 → 活耕地（GUI 交互转换，无世界方块参与）
- **种植**：活种子右键活耕地 → 写入作物类型标记，**消耗与耕地堆叠数等量的种子**
  （数量不足无法种植，triggerFilter 组合过滤保证不拦截原版交换）
- **催熟**：活骨粉右键 → 强制触发一次生长 tick（必定成功：未成熟 +1 / 成熟触发产出；
  无变化不消耗）
- **生长**：世界轴时间戳节拍（200t），湿润传播（水源相邻=3 级沿活耕地逐跳 -1，
  ≥1 即湿润 f=3.0），原版随机刻概率公式；生长与生长槽状态完全解耦
- **产出**：输出不限速（冻结后每 tick 推进）+ 概率驱动获取（成熟等概率 tick 成功才
  滚战利品表）+ 留种（cropSeed 产出项 -1 变相自动补种）+ 采后回退
  （浆果丛回 age=1 原版采摘语义，其余回 0）；×耕地堆叠数到上方生长槽
- **渲染**：双槽——耕地槽叠加**种子物品图标**（类型区分）+ 上方空生长槽绘制阶段大图；
  湿润时耕地图标切原版 farmland_moist 深色纹理（LIVING_FARMLAND_MOIST 组件驱动）
- **作物覆盖**：Block 白名单（CropBlock/StemBlock/NetherWartBlock/SweetBerryBushBlock）
  + c:seeds 标签 + 甜浆果手动映射；茎作物产出来源是果实战利品表（StemBlock.fruit AT）
