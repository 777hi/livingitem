## 架构优化建议

### 🔴 高优先级

#### 1. **活箱子存储架构重构**
**当前问题：**
- 使用原版 `DataComponents.CONTAINER` 限制为 27 槽位
- 字节上限估算粗糙（`countUsedSlots * 64`）
- 无 UUID 管理、LRU 缓存、磁盘持久化（AGENTS.md 中提到的特性未实现）

**优化方案：**
```java
// 自定义 DataComponent
public record LivingChestStorageData(
    Map<Integer, ItemStack> slots,  // 稀疏存储，突破 27 槽位限制
    int totalItems,
    int totalBytes,
    long lastAccessTime
) {
    public static final LivingChestStorageData EMPTY = 
        new LivingChestStorageData(Map.of(), 0, 0, 0);
}
```

**收益：**
- 支持动态槽位扩展（堆叠数 × 27）
- 精确字节计算
- 为未来 LRU 缓存和磁盘持久化打基础

#### 2. **ContainerFluidData 架构问题**
**当前问题：**
- 虽然已迁移到实例字段，但 `ContainerFluidData` 仍在 `SimpleContainerContext` 中持有
- 如果容器销毁，流体数据可能泄漏

**优化方案：**
```java
// 使用 WeakReference 或清理机制
public class SimpleContainerContext implements ContainerContext {
    private ContainerFluidData fluidData;
    
    public void onContainerDestroyed() {
        if (fluidData != null) {
            fluidData.cleanup();
            fluidData = null;
        }
    }
}
```

#### 3. **TickContext 创建开销**
**当前问题：**
- 每次 tick 都创建新的 `TickContext`（包含 `ContainerSnapshot.capture()`）
- 高频 tick 下可能产生 GC 压力

**优化方案：**
```java
// 对象池复用
public class TickContextPool {
    private static final ThreadLocal<TickContext> POOL = ThreadLocal.withInitial(TickContext::empty);
    
    public static TickContext acquire(ContainerContext ctx) {
        TickContext tick = POOL.get();
        tick.reset(ctx);
        return tick;
    }
    
    public static void release(TickContext tick) {
        tick.clear();
    }
}
```

#### 9. **缺少性能监控**
**当前问题：**
- 只有简单的性能日志（`LOG_PERFORMANCE`）
- 没有指标收集和可视化

**优化方案：**
```java
// 添加 Micrometer 或自定义指标
public class LivingItemMetrics {
    private static final Map<String, LongAdder> tickCounts = new ConcurrentHashMap<>();
    private static final Map<String, LongAdder> tickTimes = new ConcurrentHashMap<>();
    
    public static void recordTick(String functionId, long durationNanos) {
        tickCounts.computeIfAbsent(functionId, k -> new LongAdder()).increment();
        tickTimes.computeIfAbsent(functionId, k -> new LongAdder()).add(durationNanos);
    }
}
```
