## 待拍板（设计决策）

1. **红电 P2 补付式虚发**：信号中断 D tick 后恢复，恢复沿 interval=D 建「垃圾周期域」并在创建 tick 即入账（≈合因子×D，chunk 常载挂机可达数千 FE/tick 尖峰；有界、n=1、不构成无界刷电）。处方：`onRisingEdge` 对 `interval > max(4×periodEMA, aliveWindow)` 不喂 EMA、重置 `intervalsSeen=0`。`SignalTracker.java:30-43` + `living-power-tech.md §6.5`。
2. **末影箱路由 P2 路由表维度盲**：路由条目 containerKey/注册者键全是裸键（无维度），validateRoutes 的 isRegistrar 判定与注册期 removeByPositionAndSlot 均无维度守卫 ⇒ 跨维度同坐标容器互相删路由（check3 有守卫——守卫只做了一半；`8ea9aad` 特意不动的取舍前提不完整）。处方：注册键加维度前缀（`stripDimPrefix` 已兼容，解析侧零改动）+ isRegistrar 补维度比对 + posIndex 键带维度。`EnderChannelRegistry.java:520-534`、`EnderRouteManager.java:175-179`。
3. **TNT 哑弹「换容器即爆」设计收口**：哑弹保持 ignited+引信 0，每 tick 重试 ignite；挪进有锚点容器/掉落 ⇒ 下一 tick 立即爆（`2ecdfb5` 自己预警过需重新设计，`c75defe` 配置化 + 末影箱定案开了两条可达路径）。后果已留痕（config 注释 + EnderChestContext javadoc）。可选：点燃前判锚点 / 哑弹熄灭并接受红石重新点燃循环 / 可见留痕。
4. **Sable 飞艇 Y 公式**：文档 §11.2.1 `newAirshipY = destY - offsetY`（落地到 destY）；代码 `SableIntegration.java:137` 为 `Math.max(currentAirshipY, destY)` ⇒ 目标低于当前高度时保持旧高度 = 高空自由落体。疑为防飞艇插地的未记录修改——需真机裁决后统一。
5. **下界落点**：v28→v29 的「hasCeiling 天花板向下扫描 + 跳过岩浆」修复在 v50 简化时丢失（现行代码只剩 MOTION_BLOCKING 直读）；与已修的 Y+1 叠加 ⇒ 下界落点嵌基岩天花板/岩浆海。`TeleportHelper.java:57-63`。
