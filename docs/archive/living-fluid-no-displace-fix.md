# 消除「异种流体被当拍驱逐 ⇒ 接触前出现空档」

> **性质**：行为修正（用户 2026-10-07 在「不修 / 修」之间选**修**，理由是手感优先：
> 「水凭空消失一格」看起来就像 bug）。
> 前置阅读：`living-fluid-tech.md` §3.5（跨流体反应四格场景）、§3.6（统一时钟三分表）。

## §1 现象

把活熔岩倒在活水流旁边 ⇒ **倒的瞬间两个流体中间空出一格**，约 1.5s 后那格变成圆石。
反向（倒水进岩浆流旁）空档只有 0.25s，几乎看不见。

## §2 根因（三条规则叠加，**不是丢数据**）

1. **目标层是混合多源 BFS、按距离先到先得**（`spread`）—— 新生的岩浆源会按距离抢下
   它到水源之间那一格（若比水源更近）；
2. **修剪是即时的**（`pruneActual`：`target.fluid() != actual.fluid()` ⇒ 当拍删）⇒ 水被**驱逐**；
3. **非源格的蔓延按该流体节拍**（岩浆 30t/格）⇒ 目标层已判给岩浆，实际层还没到 ⇒ **空档**。

时间线（倒岩浆于 slot 6，水源 0，水已流到 4）：

```
t=0   倒岩浆 ⇒ 源诞生(6)
t=1   目标层：岩浆抢下 5，并想抢 4（比水源近）⇒ pruneActual 当拍删掉 4 的水
      ⇒ 但岩浆 30t 才流进 4（5 先填）⇒ slot 4 空着 ≈1.5s  ⚠️
t≈30  岩浆进 4 ⇒ 与水(3)相邻 ⇒ 机制五 ⇒ slot 4 凝固成圆石 ⇒ 水再流回 4
```

## §3 定稿：目标层**不抢占异种流体实际占据的格**

```java
// 异种流体已**实际**占据该格 ⇒ 不抢（2026-10-07 定档）
FlowEntry occupied = flows.get(neighbor);
if (occupied != null && occupied.fluid() != fe.fluid) continue;
```

效果（对齐原版 `shouldSpreadLiquid` 的「接触面直接反应」）：
岩浆前沿**停在接触面**、逐格凝固；**水原地不动**；空档消失。

## §4 为什么这是「变轻」而不是「变重」

`pruneActual` 原本背**两个**职责：① 目标消失（源被汲走 / 挤没）；② **流体被换掉**（异种抢占）。
本改动把 ② 挪进 BFS（"别人的格我不抢"），`pruneActual` 只剩 ① ⇒ **职责变单一**。

**唯一变重的一条**：目标层不再是「纯 BFS 纯函数」（要读实际层 `flows`）⇒ 同一组源在不同历史下
可能给出不同目标层。影响面核对结论：
- ㊹ 等价性守卫**不受影响**（它是单流体场景 —— 两个水源 + 晋升，守卫对它惰性）；
- 晋升 / 管道 / 渲染都读实际层，不受影响；
- 已在工作区验证：全量回归只需处理本批新增用例。

## §5 保留的不对称（有意）

**播种（`generatedSources` 里的源格）仍然覆盖** —— 倒桶是玩家显式行为（上一批定稿：
「倒进异种**流动**格 ⇒ 直接覆盖」，对齐原版倒桶对液体格一律替换）。只有**蔓延**不抢占。

## §6 被否选项

| 选项 | 否掉的理由 |
|---|---|
| **不修**（只写文档） | 用户选修：「水凭空消失一格」像 bug，挫败感 > 刷石机少一格产物 |
| **提前半拍反应**（岩浆目标格已判给它、邻居是水 ⇒ 提前反应） | **无效**：空档格此刻是空的，没有实际流体可反应；等岩浆真流进去本来就是到达当拍反应 |
| **驱逐改渐进**（像原版退水那样 level 递减） | 新机制（实际层需要"干涸"过程），重量远超收益 |
| **渲染层画"目标层幽灵"** | 渲染要读目标层 ⇒ 双层渲染，比改 BFS 重得多 |
| 目标层与实际层合并成单层 | 推翻 2026-10-05 时序化整条地基 |

| G1 | **不驱逐**：水源流到 slot 4 后在旁边倒岩浆源 ⇒ slot 4 的水**当拍仍在**（核心） | `ContainerFluidDataTest` ㊾ |

## §8 遗留

- 反应产物格（圆石）与被驱逐格的差别：改后圆石落在**接触面**（水的前一格），此前落在被驱逐格 ——
  差一格，属预期（原版就是这样）。
- DOWN 特例 / soul soil + blue ice ⇒ 玄武岩、反应音效仍未做。
